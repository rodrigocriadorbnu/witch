# 🖤 Coração de Pedra

Site oficial da personagem fictícia **Coração de Pedra**.

Uma experiência digital inspirada em ocultismo, fantasia sombria e estética black metal.

## 🔮 Sobre o projeto

Coração de Pedra é uma personagem fictícia criada para uma experiência artística e de entretenimento.

O site apresenta uma atmosfera sobrenatural por meio de:

- 🎥 Vídeos e animações
- 🕯️ Elementos visuais sombrios
- 🔮 Rituais e pedidos fictícios
- 🎵 Música ambiente
- 🌑 Estética inspirada no black metal
- 🖼️ Artes e ilustrações autorais

## ⚠️ Aviso

**Coração de Pedra é uma personagem fictícia.**

Os pedidos, rituais, feitiços, mensagens e demais elementos apresentados no site fazem parte de uma experiência de entretenimento e **não possuem qualquer poder paranormal ou comprovação sobrenatural**.

O site não oferece serviços paranormais reais.
